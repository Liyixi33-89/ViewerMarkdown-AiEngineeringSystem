## 1. 背景与目标

### 1.1 背景

用户需要一个 Markdown 文档管理系统：管理端负责上传、编辑、组织文档；前台以清爽的阅读体验向访客完整回显文档内容。两端分离，避免管理操作干扰阅读体验。

### 1.2 产品形态

```
┌──────────────────────────────────────────────┐
│  前台预览门户（首页 /）—— 访客可见，纯只读        │
│  左侧目录树（只读浏览） + 顶部导航 + 内容回显      │
└──────────────────────────────────────────────┘
                    ▲ 数据同步（实时）
┌──────────────────────────────────────────────┐
│  后台管理中心（/admin）—— 需登录鉴权             │
│  上传 / 新建 / 编辑 / 删除 / 目录管理 / 回收站    │
└──────────────────────────────────────────────┘
```

### 1.3 产品目标

1. **前台**：零门槛访问，提供完整、流畅的 Markdown 渲染回显与树级导航，无任何管理入口。
2. **后台**：独立管理端，覆盖文档全生命周期管理（上传、编辑、删除、目录组织、回收站）。
3. 后台变更实时反映到前台；两端的 Markdown 渲染效果完全一致（复用同一渲染引擎）。

### 1.4 非目标（本期不做）

- 多人协同编辑
- 富文本编辑器（WYSIWYG）双向转换
- 移动端原生 App

## 2. 用户与场景

### 2.1 目标用户

| 用户角色 | 使用端 | 说明 |
| --- | --- | --- |
| 访客（读者） | 仅前台 | 浏览、搜索、阅读文档，无任何写权限 |
| 管理员 | 以后台为主 | 上传、编辑、组织文档；也可在后台预览效果 |

### 2.2 核心场景

1. **阅读场景（前台）**：访客打开首页，从左侧树选择文档，右侧立即渲染回显；滚动阅读、点击 TOC 跳转、复制代码块。
2. **检索场景（前台）**：访客在顶部搜索框输入关键词，下拉匹配结果，点击直达文档。
3. **管理场景（后台）**：管理员登录后台，上传 `.md` 文件或粘贴文本、新建/编辑文档、拖拽调整目录结构。
4. **发布场景**：后台保存文档后，前台无需刷新即可看到最新内容（实时同步）；访客正在阅读的文档被更新时给出轻提示。

## 3. 功能需求 —— 前台预览门户（首页）

### 3.1 定位与约束

- **纯只读**：前台不存在上传、新建、编辑、删除、移动、重命名等任何管理操作，不出现对应按钮与右键菜单。
- 无需登录即可访问全部已发布文档。
- 渲染能力与后台预览完全一致（共享同一渲染引擎组件）。

### 3.2 页面布局

```
┌─────────────────────────────────────────────┐
│ 顶部导航栏：Logo │ 搜索框 │ 主题切换 │ 后台入口  │
├──────────────┬──────────────────────────────┤
│  左侧目录树    │        右侧内容回显区           │
│  （只读可折叠） │     （Markdown 渲染输出）       │
├──────────────┴──────────────────────────────┤
│ 底部（可选）：版权 / 文档总数统计                │
└─────────────────────────────────────────────┘
```

- 左侧栏宽度可拖拽调整，支持整体折叠/展开（快捷键 `\`）。
- 折叠状态、选中文档、滚动位置记忆到 localStorage，刷新后恢复。

### 3.3 前台顶部导航栏

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| Logo / 产品名 | 点击回到默认文档（第一个文档或上次浏览） | P0 |
| 搜索框 | 按文档名称模糊搜索；内容全文检索（P1） | P0 名称 / P1 全文 |
| 主题切换 | 浅色 / 深色 / 跟随系统 | P1 |
| 后台入口 | 右上角小图标，跳转 `/admin` 登录页（可配置隐藏） | P0 |

### 3.4 前台左侧目录树（只读）

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 展开/折叠文件夹 | 点击箭头；支持全部展开/收起 | P0 |
| 打开文档 | 单击文档节点，右侧渲染；当前文档高亮 | P0 |
| 树内筛选 | 树顶部小输入框，输入即时过滤树节点 | P1 |
| 文件夹图标 | 区分文件夹/文档图标；空文件夹灰显 | P1 |
| 排序 | 默认后台设定的顺序（管理员可调），前台不可改 | P0 |

**明确排除**：右键菜单、拖拽、勾选、重命名、删除等一切管理操作。

### 3.5 前台右侧回显区

#### 3.5.1 Markdown 渲染能力（完整预览，P0 核心）

| 语法类别 | 支持范围 | 优先级 |
| --- | --- | --- |
| 基础语法 | 标题、粗斜体、删除线、有序/无序列表、引用、分割线 | P0 |
| 链接与图片 | 行内链接、图片；站内相对链接映射到树节点 | P0 |
| 代码块 | 行内代码、围栏代码块 + 语法高亮 + 一键复制按钮 | P0 |
| 表格 | GFM 表格，超宽横向滚动 | P0 |
| 任务列表 | `- [x]` 复选框只读回显 | P0 |
| 目录（TOC） | 正文右侧悬浮大纲，滚动高亮同步，点击锚点跳转 | P1 |
| 数学公式 | KaTeX 行内 `$...$` 与块级 `$$...$$` | P1 |
| 图表 | Mermaid 流程图/时序图（失败降级为源码块） | P1 |
| HTML 标签 | 白名单支持基础 HTML；DOMPurify 消毒，过滤 script/iframe 等 | P0 安全 |
| Emoji | `:emoji:` 短代码 | P2 |

#### 3.5.2 阅读体验

- 文档标题 + 更新时间 + 阅读量（P2）展示在正文上方；下方显示面包屑路径。
- 正文最大宽度约 800px 居中；字号 16px，行高 1.75；长文顶部显示阅读进度条。
- 代码块、表格超宽横向滚动；图片点击放大（灯箱，P1）。
- 视图切换：**预览**（默认）/ **源码**（纯文本查看，同样只读）。

#### 3.5.3 性能要求

- 50KB 文档渲染完成 ≤300ms；500KB 大文档分片懒渲染不阻塞 UI。
- 滚动全程 60fps；切换文档时记忆各文档滚动位置（会话内）。

### 3.6 前台搜索

- 输入即时下拉匹配（防抖 300ms），结果项：文档名 + 所属路径 +（全文检索时）内容摘要。
- 关键词在正文中高亮；回车直达第一个结果；Esc 清空关闭。

## 4. 功能需求 —— 后台管理中心（/admin）

### 4.1 定位与入口

- 独立路由 `/admin`，与管理操作完全收敛于此；需管理员账号登录（默认提供初始管理员账号）。
- 未登录访问后台一律重定向到登录页；前台访客与后台账号体系隔离（前台无需任何登录）。
- 布局同样为「顶部工具栏 + 左侧管理树 + 右侧工作区」三段式，但视觉风格与前台区分（如深色顶栏）。

### 4.2 后台顶栏功能

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 返回前台 | 新窗口打开首页，便于核对发布效果 | P0 |
| 上传按钮 | 打开上传对话框（见 4.4） | P0 |
| 新建下拉 | 新建文档 / 新建文件夹 | P0 |
| 回收站 | 查看与恢复已删除内容 | P1 |
| 批量导入 | 上传 zip 包按原结构生成树 | P1 |
| 导出 | 单文档 `.md` / 文件夹 zip（P2）/ PDF（P2） | P1 |
| 管理员信息 | 修改密码、退出登录 | P0 |

### 4.3 后台左侧管理树

在**复用前台树的展示能力**基础上，增加完整管理操作：

| 操作 | 方式 | 优先级 |
| --- | --- | --- |
| 展开/折叠、打开文档 | 同前台 | P0 |
| 重命名 | 右键菜单 / 更多按钮 | P0 |
| 删除 | 右键菜单（确认弹窗 → 回收站） | P0 |
| 新建子文件夹/子文档 | 右键菜单 | P0 |
| 拖拽移动节点 | 调整父子关系与排序 | P1 |
| 同级排序 | 上移/下移/拖拽 | P1 |
| 批量操作 | 勾选后批量删除/移动 | P2 |

交互细节：

- 右键菜单按节点类型（文件夹/文档）动态显示。
- 文件夹层级建议 ≤5 层；删除文件夹需二次确认并提示"将同时删除 N 个子项"。
- 所有变更**实时同步前台**（见 4.7）。

### 4.4 文档上传/新建（P0 核心）

#### 4.4.1 上传方式

1. **文件上传**：选择本地 `.md` / `.markdown`，支持多选批量。
2. **粘贴文本**：对话框粘贴 Markdown 文本，实时预览。
3. **拖拽上传**：文件拖入目标文件夹节点（P1）。

#### 4.4.2 上传对话框字段

| 字段 | 必填 | 校验规则 |
| --- | --- | --- |
| 文档标题 | 是 | ≤200 字符；默认取首个 `#` 标题或文件名 |
| Markdown 内容 | 是 | ≤2MB；UTF-8 纯文本 |
| 目标目录 | 否 | 默认根目录，下拉选择 |
| 标签（P2） | 否 | 多选 |

#### 4.4.3 校验与反馈

- 非法类型/超限给出明确错误；重名自动追加后缀（如 `文档(1)`）。
- 批量上传显示进度条与失败列表，支持单个重试（P1）。

### 4.5 文档编辑（P1）

- 右侧工作区支持「编辑」模式：左侧编辑器 / 右侧实时预览分屏。
- 工具栏：加粗、斜体、标题、链接、图片、代码块、表格快捷插入。
- 自动保存（停笔 2 秒）+ Ctrl+S 手动保存；保存后更新树上标题与前台内容。
- 版本历史：保留最近 20 版，可查看与回滚（P2）。

### 4.6 回收站（P1）

- 后台删除内容进入回收站，保留 30 天后物理删除。
- 支持恢复（原位置被占则放根目录）、彻底删除、清空。
- 回收站内容前台不可见。

### 4.7 前后台数据同步

| 场景 | 行为 |
| --- | --- |
| 后台新增/修改文档 | 前台树与正文实时更新（轮询或 WebSocket，P0 用轮询 ≤10s / P1 WebSocket） |
| 后台删除文档 | 前台树移除；若访客正浏览该文档，显示"文档已被移除"并回到默认文档 |
| 访客正阅读的文档被更新 | 正文刷新并轻提示"文档已更新" |

### 4.8 后台其他管理功能

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 文档发布状态 | 草稿（仅后台可见）/ 已发布（前台可见），默认已发布 | P2 |
| 站点设置 | 站点名、Logo、是否显示后台入口、默认主题 | P2 |
| 统计面板 | 文档总数、存储占用、最近更新、前台阅读量（P2） | P2 |
| 多管理员 | 账号管理、角色权限（超管/编辑者） | P2 |

## 5. 非功能需求

### 5.1 性能

| 指标 | 目标值 |
| --- | --- |
| 前台首屏加载（生产构建） | ≤2s |
| 文档切换渲染 | ≤300ms（50KB 内） |
| 目录树加载 | 1000 节点 ≤1s，超出启用虚拟滚动 |
| 后台保存到前台可见延迟 | 轮询模式下 ≤10s；WebSocket 模式 ≤1s |
| 并发访客 | ≥100 |

### 5.2 安全

- 前台/后台所有 Markdown 渲染输出必须经 XSS 消毒（DOMPurify）。
- 后台全部接口需管理员鉴权（Token/Session）；前台接口只读且不暴露管理能力。
- 上传仅接受文本类 Markdown，拒绝二进制伪装文件；文件名/标题入库前转义。

### 5.3 兼容性

- 浏览器：Chrome / Edge / Firefox / Safari 最近两个大版本；移动端 iOS Safari ≥15、Android Chrome ≥100。
- **前台响应式（PC + 移动端，P0）**：<768px 单栏布局，目录树为全屏抽屉（汉堡菜单），搜索为展开式图标入口，代码块/表格横向滑动；≥768px 抽屉树 + 流式正文；≥1280px 完整三栏。
- 移动端适配细则（触摸目标 ≥44px、图片懒加载、灯箱双指缩放等）见技术设计文档 2.6 节。
- 后台 `/admin` 仅保证 PC 端体验（≥1280px）。

### 5.4 数据可靠性

- 后台保存"先写后响应"，失败保留前端草稿并提示。
- 服务端每日增量备份。

## 7. 关键流程

### 7.1 访客阅读流程（前台）

```
打开首页 → 加载目录树（恢复上次状态）→ 点击文档
→ 右侧渲染回显 → 滚动/TOC 跳转/复制代码 → 切换文档时记忆滚动位置
```

### 7.2 管理员上传流程（后台）

```
登录 /admin → 点击"上传" → 选择文件或粘贴文本
→ 自动带出标题 → 选择目标目录 → 实时预览确认 → 提交入库
→ 管理树插入节点 → 前台实时可见
```

### 7.3 后台变更同步流程

```
后台保存/删除 → 服务端入库 → 前台轮询或 WS 推送
→ 前台树/正文更新 → 正在阅读受影响文档的访客收到轻提示
```

### 7.4 删除与恢复流程（后台）

```
后台右键删除 → 二次确认 → 进回收站（前台立即不可见）
→ 30 天内可恢复/彻底删除 → 超期物理删除
```

## 8. 技术方案建议

- **前端**：React 18 + Vite + TypeScript；路由用 React Router，拆分 `前台路由（/）` 与 `后台路由（/admin，路由守卫鉴权，封装 `<RequireAuth>` 高阶组件拦截未登录）`；状态管理用 Zustand（轻量）或 React Context；两端复用同一 Markdown 渲染组件与目录树组件（后台树通过 props 开启管理能力）。
- **渲染**：`react-markdown` + `remark-gfm` + `react-syntax-highlighter`（代码高亮）+ `rehype-sanitize`（XSS 白名单消毒）；或 `markdown-it` + `DOMPurify` 方案二选一；TOC 用 `remark-toc` / 自研抽取标题；公式 KaTeX（`rehype-katex`）；图表 Mermaid（按需异步动态 `import()` 加载）。
- **组件库**：Ant Design 5（后台管理端高频组件：树、弹窗、上传、表格）；前台阅读区自研轻量样式，避免管理端风格影响阅读体验。

**前端工程结构草案**：

```text
src/
├── routes/                 # 路由入口（前台 / 后台懒加载分包）
│   ├── Portal.tsx          # 前台布局（React.lazy 懒加载）
│   └── Admin.tsx           # 后台布局 + <RequireAuth> 守卫
├── layouts/
│   ├── PortalLayout.tsx    # 前台三栏布局（顶栏+只读树+回显区）
│   └── AdminLayout.tsx     # 后台布局（顶栏+管理树+工作区）
├── components/
│   ├── markdown/           # 共享 Markdown 渲染组件（两端复用）
│   │   ├── MarkdownViewer.tsx
│   │   ├── MarkdownEditor.tsx   # 后台编辑模式（P1）
│   │   └── TocPanel.tsx
│   └── DocTree/
│       ├── DocTree.tsx     # 树组件：readonly props 控制是否开启管理能力
│       └── TreeNode.tsx
├── stores/                 # Zustand：docTree / userAuth / viewerPrefs
├── pages/
│   ├── portal/             # 前台页面：Home、DocView
│   └── admin/              # 后台页面：Login、Dashboard、RecycleBin、Settings
├── api/                    # axios 封装：公开只读接口 / 鉴权管理接口
└── utils/                  # XSS 消毒、防抖、滚动位置记忆
```
- **后端**：Java（Spring Boot）；接口分 `公开只读接口`（树查询、文档内容、搜索）与 `管理鉴权接口`（CRUD、上传、回收站、设置）。
- **同步机制**：M1 前台 10s 轮询文档更新时间戳；M2 升级 WebSocket 推送。
- **数据模型草案**：

```text
doc_node 表
- id          主键
- parent_id   父节点（根为 0/null）
- name        名称（文件夹名或文档标题）
- type        FOLDER / DOC
- content     Markdown 文本（仅 DOC）
- sort_order  同级排序（后台可调）
- status      PUBLISHED / DRAFT（P2，前台仅查 PUBLISHED）
- deleted     软删除标记（回收站，前台过滤）
- created_at / updated_at

admin_user 表（后台账号，与前台访客无关）
- id / username / password_hash / role / created_at
```

- **全文检索**：名称搜索 LIKE 即可；全文检索 P1 引入 SQLite FTS 或 Elasticsearch。

## 10. 验收标准（M1）

1. 前台首页无任何管理按钮/右键菜单，访客不登录可完整浏览全部文档。
2. 前台点击树上文档 ≤300ms 完成渲染，GFM 基础语法（标题/列表/表格/代码块/图片/任务列表）显示正确。
3. 后台 `/admin` 未登录不可访问；上传 `.md` 与粘贴文本均成功入库并出现在管理树。
4. 后台保存/删除后 ≤10s 内前台同步生效；被删文档在前台消失。
5. 两端渲染输出均经 XSS 消毒，`<script>` 注入不执行。
6. 50KB 文档渲染 ≤300ms；前台刷新后树结构、选中状态与主题恢复。
7. 前台在移动端（375px 宽）无横向溢出，抽屉树可正常导航文档，代码块/表格可横向滑动。
